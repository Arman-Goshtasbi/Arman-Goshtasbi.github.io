Fluid tactile sensor

A soft tactile sensor that senses touch position and force through fluid–solid interaction, demonstrated in real-time human–robot interaction with a UR robot arm.

← All projects

Overview

A fluid-filled soft sensor infers touch position and applied force from pressure signals generated as the fluid deforms under contact, rather than from an array of discrete sensing elements. Both 1D and 2D versions were built and characterized across multiple fill media (air, oil, water), including underwater operation. A machine learning pipeline (fuzzy clustering + ANFIS) maps the raw pressure signals to position and force, and the sensor was integrated with a UR robot arm over a real-time MATLAB–Python TCP link to demonstrate live human–robot interaction — the arm responds to a touch on the sensor with a poke motion in real time.

A. Goshtasbi, M. Berghuis, A. Parvaresh, S. P. Murali Babu, R. W. Style, A. Rafsanjani, "Tactile Perception through Fluid–Solid Interaction," Nature Communications, 2026. nature.com →

Code

Three stages: raw signal processing, machine learning, and real-time robot control.

1. Raw data processing (MATLAB) — extracts peak pressure and rise time from raw sensor signals, and maximum force from experimental data, to build the ML training set.

Raw_Data_Processing.m Open →

2. Machine learning (MATLAB) — Fuzzy C-Means clustering + ANFIS, trained to map pressure signals to touch position and force for both the 1D and 2D sensors.

FCM_ANFIS_learning_tactile.m Open →

3. MATLAB–Python TCP link — MATLAB runs live signal processing and ANFIS prediction, then streams the predicted position and force to a Python server that drives a UR robot via RTDE for real-time human–robot interaction.

UR_Matlab_tcp_XF_1D.m MATLAB — sensing + prediction Open →
UR_Python_TCP_1D_XF.py Python — robot control Open →
